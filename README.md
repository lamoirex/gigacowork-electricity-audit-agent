# GigaCowork: Агент сверки коммунальных платежей

Детерминированный AI-агент для проверки начислений за электроэнергию с нормативами.

## 🚀 Быстрый старт

Запуск скрипта напрямую:

```bash
pip install -r requirements-dev.txt
python testdata/generate.py
python agent/skill/utility-check/scripts/check_charges.py \
  testdata/out/charges.xlsx testdata/out/norms.xlsx testdata/out/stores.xlsx runs/
python tools/evaluate.py runs/reconciliation.xlsx testdata/out/expected.json
```

## 📊 Метрики качества

Проект проверен на наборе данных. Подробный отчет в [runs/REPORT.md](runs/REPORT.md).

| Метрика | Значение | Как проверено |
|---------|----------|---------------|
| **Точность по статусам и правилам** | 100% | `tools/evaluate.py` |
| **Точность по суммам и отклонениям** | 100% | Сверка с `expected.json` |
| **Выдуманные значения (0 подстановок)** | Подтверждено | Оценщик проверяет пустые ячейки |
| **Воспроизводимость** | Подтверждено | Детерминированный CLI |
| **Время работы скрипта** | ~0.2 сек | `time python check_charges.py` |
| **Тесты** | 100% pass | `pytest -q` |

## 📁 Структура

- `agent/skill/utility-check/` — сам навык (SKILL.md, скрипты, справочники)
- `agent/system_prompt.txt` — системный промпт для GigaChat
- `testdata/` — генераторы и эталоны (base, foreign_format, edge)
- `tests/` — юнит-тесты и интеграционные тесты
- `runs/` — результаты прогонов и `REPORT.md`
- `docs/` — алгоритм, допущения, вопросы заказчику

## ⚙️ Принятые допущения (MVP)

1. **Порог 10%**. Сравнивается строго: `> 10%`. Ровно 10% — «в норме».
2. **Выбор версии**. Берем последнюю с `valid_from <= 1-е число периода`.
3. **Нормализация единиц**. `кВт·ч`, `кВт*ч`, `kWh` — эквивалентны. `кВт` (мощность) — уточнение.
4. **Нет даты начала**. Если у норматива пустой `valid_from`, он игнорируется.
5. **Даты не бьются**. Если даты не совпадают с заявленным периодом — «требуется уточнение».
