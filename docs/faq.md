# FAQ

Почему модель не принимает решения?
Правила формализованы, скрипт детерминирован. Модель только запускает и пересказывает.

Как поменять порог?
agent/skill/utility-check/references/params.json -> threshold_percent.

Лишние колонки в Excel?
Скрипт ищет по заголовкам, лишние игнорируются.

Выбор версии норматива?
Последняя с Действует с <= 1-е число периода. Сортировка: (дата, номер версии).

Почему 10% - норма, а не превышение?
Порог «строго больше». Ровно на границе - норма.
