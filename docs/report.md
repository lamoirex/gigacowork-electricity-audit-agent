# Отчёт по тестовому заданию

## Задача 1. Вопросы заказчику

См. docs/customer_questions.md. Всего 6 вопросов, по каждому зафиксировано допущение.

## Задача 2. Алгоритм

См. docs/algorithm.md и docs/architecture.md. 8 правил, первое сработавшее определяет статус.

## Задача 3. Синтетические данные

Генератор testdata/generate.py, 14 строк, все ловушки покрыты. Эталон в testdata/out/expected.json.

Дополнительные сценарии в testdata/scenarios/.

## Задача 4. Сборка агента

Навык в agent/skill/utility-check/. Системный промпт в agent/system_prompt.txt. Модель запускает скрипт и пересказывает JSON. Решения - детерминированный код.

## Задача 5. Упаковка в GigaCowork

SKILL.md с YAML frontmatter. Скрипты на Python 3.11+, только openpyxl и xlrd. Пути к файлам через аргументы. Справочники в references/.

## Задача 6. Контрольные прогоны

3+ прогона на синтетике. Метрики: accuracy, стабильность хешей, время ответа.

## Задача 7. Что сдаём

1. Архив навыка: dist/utility-check.zip
2. Системный промпт: agent/system_prompt.txt
3. Инструкция: agent/INSTALL.md
4. Синтетика: testdata/
5. Эталон: testdata/out/expected.json
6. Результаты прогонов: runs/
7. PDF: этот отчёт в pdf
