# Сборка материалов для сдачи

Установите зависимости из requirements-acceptance.txt в окружение Python 3.11+. Команда `python tools/acceptance.py` создаёт контрольные данные, запускает проверки и собирает PDF и архивы в submission/. Для локального режима доступен флаг --offline. Для режима GigaChat используются GIGACHAT_CREDENTIALS, при необходимости GIGACHAT_CA_BUNDLE и GIGACHAT_SCOPE. Каждый из трёх наборов проходит три независимых запуска. Для разовой проверки произвольных входных файлов запустите `python tools/run_agent.py charges.xlsx norms.xlsx stores.xlsx result`.

Подтверждение работы в интерфейсе GigaCowork требует выбора агента, трёх вложений и отправки без запроса. Сохраните полученную книгу, ответ и длительность, повторите в новых чатах и сопоставьте результат с тем же эталоном.
