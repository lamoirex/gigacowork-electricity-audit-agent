# Форматы входных данных

## charges.xlsx

Обязательные колонки: ID магазина, Период (YYYY-MM), Начало / конец периода, Тип начисления, Потребление, Единица измерения, Сумма без НДС.

Необязательные: Номер документа, Лицевой счёт, счётчик, тариф.

## norms.xlsx

Обязательные колонки: ID магазина, Период, Норматив потребления, Единица измерения, Норматив суммы, Версия, Действует с.

## stores.xlsx

Обязательные колонки: ID магазина.
