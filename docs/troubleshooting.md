# Решение проблем

## «требуется уточнение» у всех строк

Проверьте наличие колонок ID магазина, Период, Потребление.
Синонимы - в references/column_synonyms.json.

## «несовпадение единиц»

кВт - мощность, кВт·ч - энергия. Скрипт не пересчитывает между ними.

## «нет норматива»

- Запись в norms.xlsx для пары (магазин, период);
- Действует с <= первое число периода;
- ID после нормализации совпадает.

## pytest на Python 3.14

В tests/_helpers.py модуль регистрируется в sys.modules - обход бага dataclasses в 3.14. Для продакшена - 3.11/3.12.
