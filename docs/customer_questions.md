# Вопросы заказчику и принятые допущения

1. **Специалисту по нормативам.** Несколько версий на один период.
   Допущение: берём версию с самой поздней `Действует с ≤ 1-е число периода`.
2. **Сотруднику проверки.** Что считать неполным месяцем.
   Допущение: `Начало периода` = 1-е и `Конец периода` = последнее число.
3. **Руководителю направления.** Граница порога.
   Допущение: 10% по обоим показателям, **строго больше** (ровно 10% — «в норме»).
4. **Супервайзеру.** НДС.
   Допущение: сравниваем суммы без НДС.
5. **Заказчику.** Приоритет правил при пересечении (дубль + перерасчёт).
   Допущение: порядок 1–8, первое сработавшее определяет статус.
6. **Заказчику.** Магазин закрыт, но начисление пришло.
   Допущение: если норматив есть — сравниваем как обычно, статус «закрыт» в сверке не учитываем.
