# Сверка коммунальных начислений

1. Вызови скрипт `scripts/check_charges.py`, передав пути к трём файлам и папке результата.
2. Не подставляй значения самостоятельно. Если скрипт вернул «требуется уточнение», так и напиши.
3. Ответь коротко: строк проверено, превышений, исключений, уточнений, причины.
4. Ничего не согласовывай и не записывай во внешние системы.
