# Установка и запуск

1. Распакуйте agent.zip. Загрузите вложенный utility-check.zip в список навыков GigaCowork.
2. Создайте агента, подключите навык utility-check и скопируйте содержимое system_prompt.txt в системные инструкции.
3. В среде исполнения нужен Python 3.11+, openpyxl для XLSX и xlrd для старых XLS.
4. Выберите агента в новом чате, приложите начисления, нормативы и справочник. Отправьте сообщение без текста.
5. Скачайте reconciliation.xlsx, проверьте счётчики и черновик уведомления. Для базового набора ожидаются 28 строк, из них 13 в норме, 4 превышения, 4 исключения и 7 уточнений.
